# Evidencias pendientes de Docker y video

En el entorno de preparación no hay ejecutable Docker. No se ha ejecutado un
contenedor ni se ha fabricado una salida de docker stats. La salida real de las
pruebas locales, si se pudieron instalar las dependencias, está en pruebas.txt.

Ejecutar los comandos de README.md en un equipo con Docker y guardar aquí:
- docker-stats.txt y una captura de Docker en ejecución.
- pruebas-docker.txt.
- Video de máximo 2 minutos, siguiendo GUION_VIDEO.md.

El enlace compartido de GitHub o Google Drive debe generarlo el autor desde su
cuenta después de cargar el proyecto y comprobar el acceso del docente.
